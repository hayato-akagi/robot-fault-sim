# Normal Operation Criteria

## 正常サイクルの判定条件

以下をすべて満たす場合、エピソードは NORMAL と判定される。

- すべての関節トルクが定格最大値の 110% 未満（全ステップ通じて）
- エンコーダ偏差が全ステップで < 0.05 rad
- パケットロスなし
- 制御ループ周期が全ステップで < 25 ms
- 収束時の IK 残差 < 0.10
- エピソードが max_steps 以内に完了（500 ステップ）

## タスクフェーズ

| フェーズ | 名前 | 説明 |
|---|---|---|
| 1 | HOME | ホームポジションへ戻る |
| 2 | APPROACH | 対象物の上方へ移動 |
| 3 | GRASP | 降下してグリッパーを閉じる |
| 4 | LIFT | 持ち上げる |
| 5 | MOVE | 目標位置へ移動 |
| 6 | RELEASE | 降下してグリッパーを開く |
